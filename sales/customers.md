# Customers

Manage your customer records: the companies and people you quote, invoice and run jobs for. A customer is picked on every quotation, logistics file and sales invoice.

## Overview

Go to **Sales → Customers**. The list shows each customer's type, email, phone, city and status. Use the search box, the **All Status** and **All Types** filters, or **Add Filter** to narrow it down. Use the pencil icon to edit a customer.

![Customers list](/images/import-walkthrough/customers-list.jpg)

## Adding a Customer

1. Select **New Customer**.
2. Choose the **Customer Type**:
   - **Individual**: enter **First Name** and **Last Name** (both required).
   - **Business**: enter the **Company Name** (required).
3. Optionally add the **TIN Number** and **VRN Number**.
4. Under **Contact Information**, add the **Email** and **Phone**.
5. Under **Address**, fill in **Address Line 1**, **Address Line 2**, **City**, **State/Province**, **Postal Code** and **Country**. Start typing the country and choose it from the list.
6. Leave **Status** as **Active** (or set it to inactive for customers you no longer work with).
7. Select **Create Customer**.

![New Customer form](/images/import-walkthrough/customer-new-top.jpg)

![New Customer form: address and status](/images/import-walkthrough/customer-new-bottom.jpg)

After saving, the form opens as **Edit Customer**, where you can make changes and select **Save Changes**.

::: tip Adding a customer on the fly
On a quotation you can also add a customer while searching. Type the name and choose **Add New Customer**.
:::
