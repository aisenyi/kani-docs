# Reports

Go to **Admin and Reports → Reports**. Reports are grouped into four sections.

Instructions for filtering and exporting each report still need adding.

## Daily Customer Reports

Currently active files, for sending customers a daily update:

| Report | Covers |
|---|---|
| **Daily Customer Report - Imports** | Open imports, plus those closed in the last 2 days |
| **Daily Customer Report - Exports** | Open exports, plus those closed in the last 2 days |
| **Daily Customer Report - Freight Forwarding** | Open freight forwarding jobs, plus those delivered in the last 2 days |
| **Daily Customer Report - Trips** | In-progress trips, plus those completed in the last 2 days |

## Operational Reports

Pick a date range:

| Report | Covers |
|---|---|
| **Imports Report** | All imports created within the period |
| **Exports Report** | All exports created within the period |
| **Trips Report** | All trips created within the period |
| **Freight Forwarding Report** | All freight forwarding jobs created within the period |

## Performance & Finance

| Report | Covers |
|---|---|
| **Sales Report** | Sales performance over a period |
| **Customer Statement** | Paid and unpaid invoices for a customer over a period |
| **File Profitability Report** | Expenses, invoiced revenue and profit or loss per logistics file |
| **Truck Profitability** | Income, fuel, tyres and other expenses per own truck |
| **Trip Profitability** | Income, fuel, expenses and profit per trip leg |
| **Trip Cost Summary** | Expenses and fuel per trip, main and return legs combined |

## Workshop

| Report | Covers |
|---|---|
| **Cost per Vehicle** | What each vehicle and trailer has cost to maintain |
| **Labour Cost by Task** | How often each service task is done and what the labour costs |
| **Spare Parts Spend** | Parts used on completed jobs, most expensive first |
| **Tyre Performance** | Cost per km by brand, pattern and size, cheapest first |

## Daily Report Update Tool

**Admin and Reports → Daily Report Update Tool** isn't a report. It's where you record the latest status of each open file, which then feeds the daily customer reports. Choose the **Document Type** (Imports, Exports, Freight Forwarding or Trips) to see each open file with its **Last Status Recorded**, and enter a **New Remark**.
