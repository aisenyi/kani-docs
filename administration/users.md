# Users

Manage the people who can sign in to your company's Kani LMS.

## Overview

Go to **Administration → Users**. The list shows each user's name, email or phone, role and status. Filter by **Status** (**Active** or **Inactive**) and by **Role**.

## Adding a User

1. Select **Add User**.
2. Under **User Details**, enter the **First Name** and **Last Name**, plus an **Email**, a **Phone Number**, or both. Either one can be used to sign in.
3. Under **Account Setup**, choose:
   - **Set password now**, and enter the **Password**. Use this for a user who has a phone number but no email address.
   - **Send invite email**, so the user sets their own password. This needs an email address.
4. Leave **Active** ticked so the user can sign in.
5. Under **Role & Permissions**, pick a **Role**, or choose **Custom permissions** and tick the individual permissions this user needs.
6. Save the user.
