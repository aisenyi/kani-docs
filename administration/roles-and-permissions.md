# Roles & Permissions

Roles are reusable permission templates. Users assigned a role get exactly its permissions.

For how roles and permissions work, see [Getting Started → Roles & Permissions](/getting-started/roles-and-permissions).

## Overview

Go to **Administration → Roles**. The list shows each role's name, description, how many **Users** have it, its **Type** (**System** for the three built-in roles) and how many **Permissions** it includes. Select **New Role** to create one.

| Role | Description |
|---|---|
| **System Admin** | Full access to all features |
| **Logistics Manager** | Can manage operations and approve expenses, cannot delete records or manage users |
| **Logistics User** | Standard access: view and create records |

## The Permission Matrix

Permissions are grouped by area (for example **Documents**, **Commercial** and **Party Data**). Each page has **view**, **create**, **edit** and **delete**, and some have extra rows for attachments, expenses and fuel requests. **Select all** and **Clear all** work for the whole list or a single group.

## Editing an Existing Role

Changes to a role apply immediately to every user assigned to it.
